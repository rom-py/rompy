# Templates and rendering

A model configuration renders its input files from a cookiecutter template. YAML configurations can also use `${VAR}` substitution.

## `rompy.core.render`

::: rompy.core.render
    options:
      show_root_heading: false
      heading_level: 3

## `rompy.templating`

::: rompy.templating
    options:
      show_root_heading: false
      heading_level: 3
