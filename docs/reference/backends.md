# Run backends

Backends run a generated model: locally, in Docker or on a SLURM cluster. Each backend has a configuration class, used with [`ModelRun.run`][rompy.model.ModelRun.run].

## `rompy.backends.config`

::: rompy.backends.config
    options:
      show_root_heading: false
      heading_level: 3

## `rompy.run`

::: rompy.run
    options:
      show_root_heading: false
      heading_level: 3

## `rompy.run.docker`

::: rompy.run.docker
    options:
      show_root_heading: false
      heading_level: 3

## `rompy.run.slurm`

::: rompy.run.slurm
    options:
      show_root_heading: false
      heading_level: 3
