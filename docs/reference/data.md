# Data

Data objects fetch or extract input data and write it to the run directory: [`DataBlob`][rompy.core.data.DataBlob] copies files, while [`DataPoint`][rompy.core.data.DataPoint] and [`DataGrid`][rompy.core.data.DataGrid] select data from a source over the model grid and period.
