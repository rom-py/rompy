# Postprocessors

Postprocessors act on the output of a run.

## `rompy.postprocess.config`

::: rompy.postprocess.config
    options:
      show_root_heading: false
      heading_level: 3

## `rompy.postprocess`

::: rompy.postprocess
    options:
      show_root_heading: false
      heading_level: 3
